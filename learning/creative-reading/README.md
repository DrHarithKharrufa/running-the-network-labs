# Creative reading exercises

Reading exercises for the 87-chapter edition of the book.

The book contains 12 mysteries with answers in Appendix H, workplace scenes, story openings and 51 editorial cartoons. The Configuration Workbook contains all eight branching investigations B01--B08. These Markdown copies support searching and accessible reading; they contain supplied fictional observations, not additional lab execution results. The source integration ledger records adaptations, including the condensed Chapter 15 scene. Original editorial proposals and placement guides are retained under the source QA/creative/reference-kit folder, not presented here as current integration instructions.
