# Chapter 91: reconcile executive metrics

Run `python dashboard_metrics.py` and `python -m unittest -v` with Python 3.12+.
Only the standard library is required. There are no network calls or credentials.

All fixtures are invented. The complete-event-log declaration is a teaching assumption,
not something the script discovers from production records. Four equal customers are
eligible for the entire hour. Intervals are half-open integer minutes; union is per
customer before summation. Dynamic populations, partial failures and unknown evidence
need a richer model; see lab87's distinct reporting boundaries.

Capacity uses constant monthly compound growth to a supplied planning trigger. It does
not establish performance at that load. The examples show overdue, breached, reached,
unknown-input rejection and no-finite-crossing cases. Change bounds retain unresolved
outcomes. Restoration retains unresolved ages beside completed durations. Automation
effort components are assumed non-overlapping and are capacity, not cash savings.

The output is not telemetry, a trial of an automation system, a personnel assessment,
a forecast guarantee, vendor NOS execution or a verified production board report.
